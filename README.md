# TO-DO-LIST PROJECT

מטרת הפרויקט - פיתוח פלטפורמה לניהול משימות, כולל יצירה, עריכה, מחיקה ועדכון, תוך שימוש במסד נתונים - MongoDB, כתיבת שרת fastAPI בפייתון, ופרונט ב React + TS.


## מבנה נתונים


**Users**

| שדה | סוג נתון | תיאור |
|---|---|---|
| `_id` | ObjectId | מזהה ייחודי (מיוצר ע"י מונגו) |
| `name` | String | שם המשתמש |
| `email` | String | כתובת אימייל |
| `password_hash` | String | סיסמה מוצפנת |

**Tasks** 

| שדה | סוג נתון | תיאור |
|---|---|---|
| `_id` | ObjectId | מזהה ייחודי למשימה |
| `title` | String | תיאור מהות המשימה |
| `description` | String | תיאור חופשי |
| `status` | String | מצב ההתקדמות (`pending`, `done`) |
| `user_id` | ObjectId | הפניה למשתמש המבצע (מתוך Users) |
| `created_at` | DateTime | תאריך ושעת יצירת המשימה |

## BackEnd

* חיבור לדטאבייס
* ניהול בקשות לדטאבייס - DAL
* סרוויסים לניהול לוגיקה עסקית
* שליטה בראוטים וניהול השרת

## EndPoints

### Users

| Method | Route | תיאור | Body |
|---|---|---|---|
| `POST` | `/auth/register` | הרשמה ויצירת משתמש חדש (כולל הצפנת סיסמה) | `name, email, password` |
| `POST` | `/auth/login` | אימות זהות והנפקת טוקן גישה (JWT) | `email, password` |
| `GET` | `/users` |  הצגת רשימת המשתמשים |
| `GET` | `/users/:id` | הצגת פרטי משתמש |

### Tasks

| Method | Route | תיאור | Body |
|---|---|---|---|
| `GET` | `/tasks` | הצגת כל המשימות ||
| `GET` | `/tasks/:id` | הצגת משימה לפי מזהה||
| `POST` | `/tasks` | הוספת משימה חדשה | `title, description, user_id` |
| `PUT` | `/tasks/:task_id` | עדכון משימה | `title, description, status, user_id` |
| `DELETE`| `/tasks/:task_id` | מחיקת משימה לצמיתות | |


## FrontEnd

* ניהול קריאות רשת ותקשורת מול השרת (axios)
* ניהול מצב גלובלי (state) לשמירת נתוני משתמש וטוקן גישה
* הגדרת טיפוסים ב-TypeScript לדיוק מול המידע החוזר מהמסד
* שליטה בניתובים בין דפים והגנה על מסכים הדורשים התחברות
* פיתוח רכיבי תצוגה וטפסים

## Screens & Components

### עמודים מרכזיים (Pages)

| מסך | נתיב (Route) | תיאור |
|---|---|---|
| **Login** | `/login` | עמוד המכיל טופס התחברות למערכת |
| **Register** | `/register` | עמוד המכיל טופס הרשמה למערכת |
| **Dashboard** | `/` | לוח המשימות המרכזי המציג את המשימות של המשתמש |

### קומפוננטות מרכזיות

* **Navbar:** סרגל ניווט עליון להצגת שם המשתמש וכפתור התנתקות.
* **TaskCard:** כרטיסייה המציגה משימה בודדת, כולל כפתורים למחיקה ושינוי סטטוס.
* **TaskForm:** טופס המאפשר יצירת משימה חדשה או עריכת תוכן של משימה קיימת.
* **ProtectedRoute:** קומפוננטה שחוסמת גישה לעמוד המשימות למי שאין לו טוקן תקף.
